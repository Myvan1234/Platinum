# Platinum Technology – Frontend

React + Vite + React Router. Nội dung nằm ở `shared/content.json`.

## Chạy
```bash
cd frontend && npm install && npm run dev      # http://localhost:5173
npm run build                                   # xuất ra dist/ (cần rewrite mọi route về index.html)
```

## Ghi chú
- Chưa có backend. Form liên hệ kiểm tra dữ liệu rồi mở email (mailto) tới contact@platinumtechnology.net; không lưu dữ liệu.
- Thiếu dữ liệu từ doanh nghiệp: lịch sử, tầm nhìn, sứ mệnh, hoạt động cộng đồng, chi tiết dự án/sản phẩm, ảnh, hotline 24/7.
- Logo "pt" là biểu tượng tạm.
